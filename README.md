## Formula One constructor index

A Formula One analytics application focused on constructor performance.

## Project goals

This project showcases modern Next.js patterns through an analytics application.

## Features
- Server Components
- Streaming with Suspense
- Partial Prerendering (PPR)
- Dynamic routes
- Component-level data fetching

## Stack
- Next.js
- Typescript
- Drizzle ORM
- shadcn/ui
